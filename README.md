# Pratham Kapadia — Web Technologies Portfolio

A responsive, dark-neon personal portfolio made with **plain HTML, CSS, and JavaScript**. No framework, build step, or package installation is required.

## Files

- `index.html` — page content and structure
- `style.css` — layout, responsive styling, custom CSS graphics, and animations
- `script.js` — mobile navigation, scroll reveals, pointer glow, and footer year
- `assets/profile.jpg` — optional personal photo (add your own image if you want to use one)

## Run locally

Open `index.html` in a browser. For local development, you can also use the Live Server extension in Visual Studio Code.

## Personalize before publishing

1. Add your own photo in `assets/profile.jpg` if you want to use it. The current design uses a stylized “P” graphic, so no photo is required.
2. Update your real projects and project links in `index.html`. The included project cards are clearly presented as concepts/starting examples.
3. Add an email address and any social links you want to publish in the contact section.
4. Review all details before making the repository public.

## Publish with GitHub Pages

1. Sign in to GitHub as `Prathamkapadia427`.
2. Create a new repository. For a standard project site, a repository named `web-technologies-portfolio` is fine. A user site can instead use the exact repository name `Prathamkapadia427.github.io`.
3. Upload `index.html`, `style.css`, `script.js`, and this `README.md` to the **root** of the repository. If you add a photo, upload the `assets` folder too.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, select **Deploy from a branch**. Select the `main` branch and `/(root)`, then save.
6. Wait for GitHub Pages to finish deploying. The Pages screen will show the published URL.

For a project repository, the URL usually looks like `https://Prathamkapadia427.github.io/web-technologies-portfolio/`. For a user-site repository named `Prathamkapadia427.github.io`, the URL is `https://Prathamkapadia427.github.io/`.

## Safety checklist

- Never put passwords, API keys, personal access tokens, private phone numbers, or private addresses in your website or repository.
- Anything in a public repository and published website can be viewed by others.
- Only publish a photo and contact details you are comfortable sharing publicly.
- Use GitHub's website to upload the files if you do not want to install Git.
